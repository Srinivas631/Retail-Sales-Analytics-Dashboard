# Python Analysis

## Overview

This folder contains Exploratory Data Analysis (EDA) performed on the Retail Sales dataset using Python.

The objective was to clean, transform, analyze, and visualize retail sales data to uncover business insights related to sales performance, profitability, customer behavior, and geographical trends.

---

# Files

### EDA_Analysis.ipynb

Jupyter Notebook containing:

- Data Loading
- Data Cleaning
- Data Transformation
- Exploratory Data Analysis
- Data Visualization
- Business Insights

---

# Libraries Used

- Pandas
- NumPy
- Matplotlib

# Data Preparation

The following preprocessing steps were performed:

### Data Cleaning

- Verified missing values
- Checked data types
- Converted date columns into datetime format
- Created Month column for trend analysis
- Validated numerical fields

### Feature Engineering

- Shipping Days Analysis
- Monthly Sales Aggregation

# Exploratory Data Analysis

## 1. Sales by Category

### Objective

Identify categories generating the highest sales.

### Visualization

Bar Chart

### Key Insight

- Chairs generated the highest revenue.
- Phones and Tables were also strong contributors.

---

## 2. Monthly Sales Trend

### Objective

Analyze sales performance over time.

### Visualization

Line Chart

### Key Insight

- Sales showed an increasing trend from 2011 to 2014.
- Seasonal fluctuations were observed throughout the period.

---

## 3. Profit by Category

### Objective

Compare profitability across product categories.

### Visualization

Bar Chart

### Key Insight

- Copiers generated the highest profit.
- Some categories produced lower profits despite strong sales.

---

## 4. Top 10 Products by Profit

### Objective

Identify the most profitable products.

### Visualization

Bar Chart

### Key Insight

- Canon imageCLASS 2200 Advanced Copier generated the highest profit.

---

## 5. Profit Distribution

### Objective

Understand the distribution of profits across transactions.

### Visualization

Histogram

### Key Insight

- Most transactions generated moderate profits.
- A few transactions contributed exceptionally high profits.

---

## 6. Top States by Profit

### Objective

Analyze geographical profitability.

### Visualization

Bar Chart

### Key Insight

---

## 7. Top Customers by Sales

### Objective

Identify customers contributing the highest revenue.

### Visualization

## 8. Customer Segmentation (RFM Analysis)

### Objective

Segment customers based on purchasing behavior.

### Metrics Used

- Recency
- Frequency
- Monetary Value

### Customer Groups

- High Value Customers
- Medium Value Customers
- Low Value Customers

### Key Insight

- High-value customers generated a significant share of revenue and profit.

---

# Business Insights Generated

- Chairs generated the highest sales revenue.
- Copiers generated the highest profit.
- California was the most profitable state.
- Sales increased consistently between 2011 and 2014.
- High-value customers contributed a large portion of total revenue.
- Product profitability varied significantly across categories.
