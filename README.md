# Retail-Sales-Analytics-Dashboard
## Project Overview
This project demonstrates an end-to-end Data Analytics workflow using Excel, SQL, Python, and Power BI. The objective was to analyze retail sales data, identify business trends, evaluate product performance, understand customer behavior, and assess geographical and shipping performance

## Tools & Technologies
* Microsoft Excel
* MySQL
* Python
* Pandas
* NumPy
* Matplotlib
* Power BI

## Project Workflow
## 1. Data Cleaning (Excel)
* Removed duplicates
* Standardized date formats
* Created Shipping Days column
* Validated missing values
* Prepared dataset for analysis

## 2. SQL Analysis
Performed business-focused analysis including:
* Top 10 Products by Profit
* Monthly Sales Trend
* Top Customers by Revenue
* Sales vs Profit by State
* Category-wise Profit Margin
* Shipping Performance Analysis
* Revenue Contribution Analysis

## 3. Python EDA
Performed Exploratory Data Analysis using Pandas and Matplotlib:
* Sales by Category
* Monthly Sales Trend
* Profit by Category
* Top Products Analysis
* Customer Analysis
* State-wise Profit Analysis

## 4. Power BI Dashboard
Created a 4-page interactive dashboard:

## Executive Overview
* Total Sales
* Total Profit
* Total Orders
* Total Customers
* Monthly Trends
* Category Performance
## Product Analytics
* Product Revenue Analysis
* Product Profit Analysis
* Revenue Contribution by Category
* Product Profitability Matrix
## Customer Analytics
* Customer Revenue Analysis
* Customer Profit Analysis
* Customer Value Matrix
* Revenue Contribution Analysis
## Geography & Shipping Analytics
* State-wise Sales & Profit
* Shipping Performance
* Geographical Sales Distribution
* Profit vs Shipping Days Analysis
